# L150 Ackermann Autonomous Navigation, Obstacle Avoidance, Follow-Car & Localization Simulation

MATLAB/Simulink 仿真项目，面向 WHEELTEC L150-C30D SE 阿克曼转向小车，包含自主导航与避障、自动跟车和二维自主定位三个部分。

## 1. 项目简介

项目使用 Ackermann 运动学模型，结合虚拟二维激光雷达、占用栅格地图、Hybrid A*、路径跟踪、目标跟踪和蒙特卡洛定位，探索小车在静态障碍物及动态场景中的自主运动。

目前完成的是软件仿真。真实 LD14P 雷达接入、STM32 控制接口和实车运行效果尚未验证。

## 2. 系统架构

### 2.1 自主导航与避障

仿真环境 → 激光雷达扫描 → 障碍物坐标计算 → 已知地图更新 → 重新规划触发 → Hybrid A* → 路径分段管理 → 路径跟踪控制器 → Ackermann 运动学模型 → 状态反馈。

### 2.2 自动跟车

| 模块 | 功能 |
| --- | --- |
| FrontCar | 生成前车直行、转弯和停车轨迹 |
| TargetTracker | 根据仿真车辆状态计算目标相对位置 |
| VirtualLidar | 模拟 720 点二维激光雷达扫描 |
| LidarTargetTracker | 点云聚类、目标关联、运动预测与目标锁定 |
| FollowController | PI 距离控制、相对速度反馈、预测制动与转向控制 |
| Ackermann Kinematic Model | 模拟后车运动学行为 |
| XY Graph / Scope | 显示轨迹、跟车距离和状态变化 |

自动跟车数据流：

`FrontCar → TargetTracker → VirtualLidar → LidarTargetTracker → FollowController → Ackermann Model`

车辆状态同时反馈给目标跟踪与控制模块，形成闭环。

### 2.3 二维自主定位

```text
已知二维地图
     ↓
初始激光雷达扫描
     ↓
全地图粗搜索匹配 → 局部精细搜索
     ↓
初始位姿估计
     ↓
MCL 粒子滤波 ← 里程计数据 + 后续雷达扫描
     ↓
输出位置与朝向 [x, y, θ]
```

定位搜索只使用已知地图和雷达扫描；仿真真实位姿用于生成模拟观测和评估误差，不作为初始搜索输入。

## 3. 主要功能与算法

### 3.1 车辆运动学与路径跟踪

- 基于 Ackermann Kinematic Model 建立车辆运动学模型，支持前进和倒车。
- 按车辆轴距计算转向关系，并用 Pure Pursuit 几何思想跟踪路径或目标。
- 根据规划方向自动分段，在换挡时停车等待后切换路段。

### 3.2 激光雷达与地图更新

- 使用 `rangeSensor` 模拟二维扫描，根据测距和扫描角度计算障碍物坐标。
- 使用 `binaryOccupancyMap` 表示二维环境。
- 闭环避障模型分别维护仿真环境和车辆已知地图，并根据新观测更新已知地图。
- 当前新障碍物识别逻辑仍包含针对测试场景的区域过滤。

### 3.3 路径规划与重新规划

- 使用 Hybrid A* 规划路径，并考虑最小转弯半径。
- 对障碍物设置规划安全膨胀区域。
- 支持前进、倒车混合规划和按行驶方向整理路线段。
- 在新增障碍物场景中触发规划，并在短暂停车后切换到新路线。

### 3.4 自动跟车

- 对前方雷达区域进行筛选和连续点云聚类，计算候选目标中心。
- 根据连续帧的位置预测和数据关联门限跟踪目标，降低目标误切换。
- 由连续测距变化估算相对接近速度，无需直接读取前车真实速度。
- 使用 PI 距离控制、相对速度反馈和预测制动控制纵向速度，并计算横向转向。
- 目标无效或丢失时向控制器报告无效状态并停车。

当前目标关联依赖几何位置和运动连续性，不具备可靠的车辆身份识别能力。

### 3.5 二维自主定位

- 第一阶段在已知地图的自由区域中枚举候选位置和朝向，以模拟扫描与观测扫描的平均绝对距离差进行粗搜索，再在最佳候选附近精细搜索。
- 第二阶段使用 `monteCarloLocalization`，根据里程计预测和雷达观测权重更新粒子并持续估计位姿。
- 通过在模拟里程计中加入随机噪声和小幅系统误差，观察 MCL 对里程计漂移的修正效果。

## 4. 仿真参数与结果

### 4.1 自动跟车参数

| 参数 | 当前设置 |
| --- | ---: |
| 小车轴距 | 0.144 m |
| 控制周期 | 0.02 s |
| 期望雷达测距 | 0.7 m |
| 等效车辆参考点间距 | 约 0.8 m |
| 最大后车速度 | 0.25 m/s |
| Kp / Ki / Kd | 0.8 / 0.25 / 1.0 |
| 转向角范围 | -0.49～0.32 rad |
| 仿真时长 | 25 s |

已初步测试前车匀速直行、左转、停车、目标丢失、轻微测距扰动、多目标干扰和运动预测跟踪。当前测试中，后车行驶时的参考点距离约为 0.81 m，前车停车后稳定在约 0.79 m（根据仿真图像估读）。这些结果只代表当前理想化仿真场景，不构成真实环境中的跟踪可靠性或碰撞安全保证。

### 4.2 自主导航与避障结果

- 静态地图规划、前进与倒车跟踪，以及新增障碍物后的雷达观测、地图更新和重新规划均有对应仿真模型。
- 在预设障碍物地图的自动重规划测试中，记录的终点位置误差为 **0.079 m**。雷达感知地图驱动闭环的结果应以该模型对应的最新测量值单独记录。
- 一组避障控制仿真中的最大前轮转向角为 **0.1677 rad**（设定上限 0.25 rad），最大转向角速度为 **0.1496 rad/s**（设定上限 0.35 rad），该组结果满足相应的仿真转向约束。

### 4.3 二维自主定位参数

| 参数 | 设置 |
| --- | ---: |
| 地图尺寸 | 6 m × 4 m |
| 栅格分辨率 | 20 cells/m |
| 模拟雷达 | 720 点/圈，角分辨率 0.5° |
| 最大模拟测距 | 4 m |
| 定位方法 | 激光雷达扫描匹配 + MCL |
| 仿真时间步长 | 0.2 s |
| 仿真步数 / 时长 | 150 / 30 s |

地图由外围墙壁和多个固定物体组成，使用非对称结构增强不同位置的扫描区分度。`localization_two_stage.m` 中的测试起点设为 `[1, 0.7, 0]`；该真实位姿只用于生成虚拟扫描和计算误差。

### 4.4 二维自主定位结果

- 此前一次局部 MCL 测试记录的平均位置误差约为 **0.0496 m**，里程计平均位置误差约为 **0.0778 m**。
- 两阶段测试中，雷达全图粗搜索和局部精细搜索能够找到接近真实起点的初始位姿。
- 另一次仅保留随机里程计噪声、未加入额外系统偏差的测试，记录的最终位置误差约为 **0.0036 m**。
- 在加入 1% 速度偏差和 0.001 rad/s 角速度偏差的测试中，真实终点为 **(5.013, 2.458) m**，MCL 估计终点为 **(5.033, 2.531) m**，最终位置误差约为 **0.076 m**。

以上均为单次仿真结果，不代表不同地图、起点或噪声条件下的平均定位精度。

运行定位脚本时会生成地图、雷达扫描、轨迹对比、误差曲线和粒子分布图。当前 iCloud 项目目录未找到单独导出的结果图片，因此仓库暂不嵌入静态截图。

## 5. 开发环境与运行

- MATLAB R2026a
- Simulink
- Robotics System Toolbox
- Navigation Toolbox
- 二维占用栅格地图、虚拟激光雷达和 Ackermann Kinematic Model

在 MATLAB 中进入仓库根目录并运行 `addpath(genpath(pwd))`，使 `planning/`、`sensing/` 和 `localization/` 中的辅助文件加入 MATLAB Path。之后可打开 `models/` 中的 Simulink 模型，或运行对应脚本：

- `localization/localization_demo.m`：单阶段 MCL 对照测试，并生成示例地图和误差图。
- `localization/localization_two_stage.m`：两阶段初始位姿搜索与 MCL 持续定位。

`localization_two_stage.m` 会自行建立包含更多特征物的地图；`localization_map.mat` 是 `localization_demo.m` 保存的示例地图。

## 6. 核心文件说明

### 自动跟车

- `models/follow_car.slx`：自动跟车闭环主模型；FrontCar、VirtualLidar、LidarTargetTracker 和 FollowController 等逻辑内嵌在模型中。

### 自主导航与避障

- `models/L150_Closed_Loop3.slx`：雷达感知、已知地图更新和自动重规划闭环模型。
- `models/L150_Closed_Loop2.slx`：基于预设障碍物地图的闭环重规划版本，可作对照。
- `models/L150_Closed_Loop.slx`：路径管理与车辆控制模型变体。
- `models/L150_Auto_Segments.slx`：分段路径跟踪与自动换挡模型。
- `models/L150_Path_Follow.slx`：基础路径跟踪模型。
- `models/L150_Reverse_Test.slx`：倒车跟踪测试模型。
- `models/ackermann02.slx`、`ackermannbizhang.slx`：较早的 Ackermann 避障模型。
- `planning/l150SenseAndPlanStep.m`：雷达扫描、已知地图更新和自动规划触发。
- `planning/l150AutoReplanSensed.m`：根据雷达更新后的地图运行 Hybrid A* 并整理路线段。
- `planning/l150AutoReplan.m`：根据预设障碍物地图生成前进/倒车路线。
- `planning/L150_Path_Plannin.m`、`planning/L150_Replan_Test.m`：静态路径规划与动态重规划测试。
- `planning/L150_Path.mat`、`planning/L150_Replan_Path.mat`：已有路径及重规划结果数据。
- `sensing/L150_Lidar_Mapping_Test.m`、`sensing/LidarTest.m`：雷达建图和虚拟雷达测试。
- `sensing/l150DynamicFront.m`、`sensing/l150ReplanLidar.m`、`sensing/l150FrontRange.m`、`l150ThreeRanges.m`：各仿真模型使用的虚拟雷达测距函数。
- `L150_Collision_Check.m`：轨迹参考点安全间隙初步检查；需要工作区中的 `xy` 矩阵，车身以半径 0.20 m 的圆近似。

### 二维自主定位

- `localization/localization_demo.m`：已知大致初始位姿下的局部 MCL 基线测试。
- `localization/localization_two_stage.m`：雷达全地图匹配初始化并使用 MCL 持续定位。
- `localization/localization_map.mat`：单阶段定位示例地图；两阶段脚本会自行建立测试地图。

## 7. 当前局限性

- 雷达、里程计和车辆运动学均为理想化仿真模型，定位精度尚未经过实车标定。
- 跟车目标关联不等同于车辆身份识别。
- 避障新目标检测含有针对测试场景的区域过滤。
- 尚未完成完整车身碰撞及扫掠空间验证。
- 路径跟踪调试阶段曾临时关闭距离触发的安全停车，实车使用前必须恢复并完善。
- 尚未完成 LD14P 雷达数据接入、车辆定位、STM32 控制接口及传感器时间同步。
