# L150 Ackermann 小车避障仿真

这是一个用 Simulink 搭建的小车避障仿真。模型里用 Ackermann 运动学描述小车，再根据虚拟雷达测到的左侧、前方和右侧距离，决定继续前进、调整方向或停车。

目前的地图里放了一个矩形障碍物。这个项目主要用来观察避障逻辑和小车轨迹，雷达距离来自 MATLAB 里的虚拟传感器函数，不是实车雷达数据。

## 文件

- `ackermannbizhang.slx`：主 Simulink 模型，包含避障决策器、转向控制器、雷达测距调用和轨迹显示。
- `l150ThreeRanges.m`：模型调用的虚拟雷达函数。它生成带矩形障碍物的占据栅格地图，并返回左、前、右三个方向的最近距离。
- `L150_Collision_Check.m`：可选的轨迹间隙检查脚本。它根据轨迹点到矩形障碍物的距离，再减去 0.20 m 的圆形安全半径，估算最小安全间隙。

## 打开和运行

1. 在 MATLAB 中打开 `ackermannbizhang.slx`。
2. 确认 MATLAB 当前路径包含本项目文件夹，或将该文件夹加入 MATLAB Path。模型需要找到 `l150ThreeRanges.m`。
3. 在 Simulink 中运行模型，查看轨迹图和各个 Scope 的输出。

模型文件由 MATLAB R2026a 保存。模型和虚拟雷达函数使用了 Ackermann 运动学、占据栅格地图和距离传感器相关组件；如果打开时提示缺少组件，请检查 MATLAB 安装的产品和工具箱。

## 轨迹间隙检查

`L150_Collision_Check.m` 需要工作区中有一个名为 `xy` 的数值矩阵，第一列是 x 坐标，第二列是 y 坐标，单位为米。准备好轨迹数据后运行：

```matlab
L150_Collision_Check
```

脚本会输出最小参考点距离和估算安全间隙，并画出轨迹与障碍物。它把车身近似成半径 0.20 m 的圆，因此结果适合快速检查，不等同于完整的车身碰撞验证。当前模型没有自动把轨迹写入 `xy`，需要先从仿真结果中整理出这个矩阵。

## 当前范围

这里保存的是仿真模型和轨迹检查脚本，不包含实车固件、雷达驱动或硬件测试记录。避障决策阈值、障碍物尺寸和安全半径都可以按后续实验需要调整。
